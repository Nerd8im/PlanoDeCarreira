# Engenharia de Dados no Brasil — Mercado, Competências e Desenvolvimento Profissional



## Sobre o Projeto

Este repositório apresenta um estudo acadêmico sobre a área de **Engenharia de Dados**, desenvolvido no contexto da formação em Análise e Desenvolvimento de Sistemas.

O trabalho tem como objetivo analisar o cenário profissional da Engenharia de Dados no Brasil, investigando as principais tendências do mercado, perspectivas de carreira, oportunidades de trabalho e competências técnicas e comportamentais exigidas pelas empresas.

A pesquisa também contempla o levantamento e a análise de vagas reais de Engenharia de Dados, permitindo identificar tecnologias e conhecimentos recorrentes, como **Python, SQL, bancos de dados, ETL/ELT, Cloud Computing, Git, Spark, PySpark, Airflow e Databricks**, além de competências relacionadas à comunicação, resolução de problemas, trabalho em equipe e aprendizado contínuo.

A partir dessa análise, o trabalho relaciona as exigências encontradas no mercado com o desenvolvimento acadêmico e profissional dos integrantes do grupo, servindo como base para a construção dos planos de carreira e Planos de Desenvolvimento Individual (PDI).

## Objetivos

- Analisar o mercado de Engenharia de Dados no Brasil;
- Identificar tendências e perspectivas profissionais da área;
- Mapear vagas reais e suas principais exigências;
- Identificar as Hard Skills e Soft Skills mais recorrentes;
- Relacionar as exigências do mercado com a formação acadêmica;
- Identificar lacunas de desenvolvimento profissional;
- Apoiar a construção dos planos de carreira e PDIs dos integrantes.

## Tecnologias e Competências Analisadas

`Python` `SQL` `Git` `GitHub` `ETL/ELT` `Bancos de Dados` `Cloud Computing` `AWS` `Azure` `GCP` `Spark` `PySpark` `Airflow` `Databricks` `DataOps`

## Estrutura do Trabalho

O projeto está organizado em uma análise coletiva do mercado de Engenharia de Dados e capítulos individuais dedicados ao desenvolvimento profissional de cada integrante, contemplando presença digital, GitHub, LinkedIn, plano de carreira, PDI, identificação de gaps e feedback por pares.

Este trabalho representa parte do processo de desenvolvimento acadêmico e profissional dos integrantes, conectando a formação universitária às demandas observadas no mercado de Tecnologia.
